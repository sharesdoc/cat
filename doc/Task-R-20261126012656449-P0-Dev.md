## 4. 设计方案

【最优解】工程+规范路径锁、双路径稳定顺序、目录层级锁；持锁重验权限/路径/版本/cwd_version；create 不存在、replace 旧哈希；严格模式要求受控工作树或统一协调；共享模式保留备份并说明 TOCTOU。

取舍与适用前提：普通 POSIX rename 无通用 CAS，不能承诺任意 IDE 不丢更新。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
