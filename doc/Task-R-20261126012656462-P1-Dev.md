## 4. 设计方案

【最优解】cat_git_status/git_diff 固定 argv、受控 cwd/env、关闭外部 diff/pager 及危险配置、超时；过滤路径内容；非 Git 明确；不能安全访问跨根 worktree 元数据时拒绝；禁止 commit/push。

取舍与适用前提：标准 Git 命令优于自解析，必须安全隔离。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
