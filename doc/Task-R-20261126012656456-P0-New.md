## 4. 设计方案

【最优解】cat_move_path 锁源/目的，校验权限、版本、目标不存在、同文件系统、源非根、目录非自身子树；目录子树版本与授权策略；安全 no-replace，日志和 cwd 失效处理。

取舍与适用前提：跨设备不隐式复制删除；目录版本契约需明确。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
