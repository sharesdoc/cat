## 4. 设计方案

【最优解】cat_trash_path：delete 权限、版本、请求 ID、cwd；工程外隔离回收区和清单；同文件系统原子移动，不能安全处理则拒绝；递归默认关闭，启用需独立审批和限额；管理员清理。

取舍与适用前提：不默认 unlink，跨设备需明确安全策略。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
