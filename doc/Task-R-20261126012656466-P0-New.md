## 4. 设计方案

【最优解】Linux 非 root 专用用户、仅授权挂载、容器系统根只读、drop capabilities/no-new-privileges、无 Docker socket/SSH/home、出站限制；Caddy/Nginx TLS、仅公网443、后端私有监听、限流；跨信任域独立隔离。

取舍与适用前提：Docker 或 systemd 实际隔离需验证，单进程非多租户安全。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
