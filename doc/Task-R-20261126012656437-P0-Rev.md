## 4. 设计方案

【最优解】对接成熟 IdP 和 SDK token verifier；校验签名、issuer、audience、expiry、scope、撤销策略；提供 protected-resource metadata；IdP 负责 PKCE/redirect URI；主体取自令牌；Host/Origin 校验；loopback 开发模式隔离。

取舍与适用前提：标准 IdP 优先，实际兼容和撤销时效待验证。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
