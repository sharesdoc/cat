## 4. 设计方案

【最优解】锁定官方 Python SDK 稳定版、MCPServer/ASGI Streamable HTTP（SDK v2；v1 才使用 FastMCP）、可选 stdio；严格 schema 与未知字段拒绝，统一 ok/request_id/error/isError；正确 readOnly/destructive 注解；实现 cat_get_capabilities；handler 不直访 OS。

取舍与适用前提：优先 SDK 内置框架，协议版本须联调。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
