## 6. 可后续优化（P2 / P3）

### P3-001: 测试文件中不必要的 noqa 注释

- **位置**：`tests/test_import.py:13`
- **事实**：`import cat_mcp  # noqa: F811`
- **依据**：`F811` 表示"变量重定义但未使用"。该条语句中 `cat_mcp` 仅 import 一次，并在下一行被引用（`cat_mcp.__version__`），不会触发 ruff 的 `F811` 或 `F401`。该 `# noqa` 注释是无效的。
- **影响**：无功能影响，仅代码清理。其余 5 个 `# noqa: F401` 正确。
- **建议**：移除 line 13 的 `# noqa: F811` 注释。

### P3-002: `load_config()` 骨架未引入 `tomllib`

- **位置**：`src/cat_mcp/config.py:126-136`
- **事实**：`load_config()` 有 TODO 标记但未 `import tomllib`。Python 3.12+ 标准库自带 `tomllib`。
- **依据**：设计方案要求使用 `tomllib`（`Cat-总体需求与技术实现方案.md §3.2`）。
- **影响**：仅骨架阶段，实际 TOML 解析由 CAT-03 实现。可留待下个任务加入 import。
- **建议**：建议在 CAT-03 实现时添加 `import tomllib`，当前可忽略。

### P3-003: 公有模块缺少 `__all__` 导出声明

- **位置**：`src/cat_mcp/schemas.py`、`src/cat_mcp/errors.py`
- **事实**：两个模块定义了多个公开类（如 `ErrorCode`、`CatError`、`AccessScope`、`WorkspaceInfo`、`FileEntry` 等），但均未声明 `__all__` 列表。
- **影响**：当前无功能影响（骨架阶段）。进入 CAT-04 工具注册后，工具模块将 `from cat_mcp.schemas import ...`，有 `__all__` 有助于 IDE 提示和静态分析。
- **建议**：可在明确导出接口时（CAT-04 前）补充 `__all__` 列表。

### P3-004: `MCPServer` 骨架使用自定义类而非 SDK MCPServer

- **位置**：`src/cat_mcp/server.py:11-57`
- **事实**：当前 `MCPServer` 是一个自定义壳类，未继承或使用官方 SDK 的 `MCPServer`（`mcp.server.MCPServer`）。设计方案明确要求使用 SDK v2.3.0 的 `MCPServer`（方案 §3.2）。
- **依据**：该设计决策有明确文档记录，当前骨架未体现。
- **影响**：骨架阶段不影响功能。CAT-04 实现协议入口时必须切换到 SDK 原生 MCPServer。
- **建议**：CAT-04 实现时删除自定义 MCPServer 类，直接使用 `from mcp.server import MCPServer`。
