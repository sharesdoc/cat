## 4. 设计方案

【最优解】cat_stat/read_file 以安全 fd 读元数据与原始 SHA-256；1-based 闭区间、max_bytes、续读行/字节偏移、expected_version；UTF-8/BOM/LF/CRLF、超长行安全续读；未知编码报错；禁止混拼版本。

取舍与适用前提：哈希优于 mtime/size；大文件哈希成本待测。。本任务采用统一 Python 自主实现路线，通用组件可直接依赖；不得绕开共享安全、版本与权限边界。方案中的接口、路径和限额须结合锁定依赖实测；不确定项不得伪装为已实现。
